Đội tuyển HSG Tin

Lộ trình chuẩn: khái niệm → nhận dạng đề → thuật toán → code → mô phỏng → test bẫy. Trang này thiết kế để vừa chiếu trên lớp vừa in làm tài liệu.

Graph: BFS/DFS, 0-1 BFS, Dijkstra, Bellman-Ford, Floyd
MST: Prim, Kruskal
Chuyên sâu: SCC, Cầu/Khớp, LCA
Tree/DS: Segment Tree, Fenwick, Trie
Mẹo chọn thuật toán: “không trọng số?”→BFS, “w∈{0,1}?”→0-1 BFS, “w≥0?”→Dijkstra, “có âm/chu trình âm?”→Bellman, “mọi cặp?”→Floyd, “xây mạng tiết kiệm?”→MST, “mạnh liên thông?”→SCC, “cầu/khớp?”→tin/low.

⚠️ Bẫy thường gặp & Test mẫu (checklist trước khi nộp)

rất hay ra đề

BFS / DFS

  • Bẫy: quên reset visited giữa nhiều test; nhầm 0-index/1-index; đồ thị vô hướng nhưng chỉ add 1 chiều.
  • Bẫy: DFS đệ quy sâu → stack overflow (n lớn) ⇒ dùng DFS iterative nếu cần.
  • Test BFS: đường đi ngắn theo số cạnh.
# Input 5 4 1 2 2 3 3 4 4 5 1 5 # Expected: dist=4, path 1 2 3 4 5

0-1 BFS

  • Bẫy: chỉ dùng khi w ∈ {0,1}. Nếu w khác → dùng Dijkstra/Bellman.
  • Bẫy: deque: w=0 push_front, w=1 push_back (đảo là sai).
# Input 4 4 1 2 0 2 3 1 1 3 1 3 4 0 1 4 # Expected: dist=1 (1->2->3->4)

Dijkstra

  • Bẫy chí mạng: có cạnh âm ⇒ Dijkstra sai.
  • Bẫy: quên bỏ bản ghi cũ trong pq (if d != dist[u] continue) ⇒ TLE.
# Input (có cạnh âm) 3 3 1 2 2 2 3 -5 1 3 1 1 3 # Expected: shortest = -3 via 1->2->3 (Dijkstra sẽ chọn 1)

Bellman-Ford

  • Bẫy: phát hiện chu trình âm bằng relax vòng n là chưa đủ; cần lan truyền ảnh hưởng chu trình âm theo cạnh để đánh dấu -2.
  • Bẫy: chỉ chu trình âm reachable từ s mới ảnh hưởng kết quả từ s.
# Input (chu trình âm reachable) 4 4 1 1 2 1 2 3 1 3 2 -3 3 4 1 # Expected: 2,3,4 bị -2 (do cycle ảnh hưởng)

Floyd-Warshall

  • Bẫy: INF quá nhỏ → sai/tràn. Dùng long long + INF rất lớn.
  • Bẫy: nếu d[i][k] hoặc d[k][j] là INF thì không được cộng.
  • Bẫy đề: ma trận có thể dùng 0 để chỉ “không có cạnh” (trừ i=j) ⇒ phải đổi sang INF.
# Input (0 nghĩa không có cạnh, trừ đường chéo) 4 0 3 0 7 8 0 2 0 5 0 0 1 2 0 0 0 # Expected: phải chuyển 0 (i!=j) thành INF rồi Floyd

MST (Prim/Kruskal)

  • Bẫy: đồ thị không liên thông ⇒ không có MST (chỉ có MSF).
  • Bẫy Kruskal: DSU unite sai ⇒ chọn cạnh tạo chu trình.
# Input (không liên thông) 4 2 1 2 1 3 4 1 # Expected: Graph not connected

SCC / Cầu-Khớp / LCA

  • SCC: quên reverse graph hoặc quên reverse order.
  • Cầu/Khớp: phải DFS từ mọi đỉnh (đồ thị có thể không liên thông). Root là khớp khi có ≥2 con DFS.
  • LCA: preprocess depth + up[k][v]. Nhầm LOG hoặc root.

🧭 Đường đi ngắn — nhận dạng đề + thuật toán

BFS / 0-1 BFS / Dijkstra / Bellman / Floyd

Nhận dạng nhanh

  • Không trọng số (mọi cạnh = 1) → BFS (queue).
  • Trọng số chỉ 0/1 → 0-1 BFS (deque).
  • Trọng số không âm → Dijkstra (priority_queue).
  • Có cạnh âm hoặc hỏi chu trình âm → Bellman-Ford.
  • Mọi cặp (all-pairs), n nhỏ → Floyd-Warshall.
Mẹo ra đề: nếu bài cố tình có cạnh âm mà bạn dùng Dijkstra → 100% sai. Nếu bài hỏi “ảnh hưởng chu trình âm” → cần lan truyền đánh dấu.

Hình minh hoạ “độ dài đường đi”

🧮 Floyd-Warshall — mô phỏng ma trận (cơ bản)

all-pairs shortest path

Floyd: thử chèn đỉnh trung gian k vào giữa (i, j): nếu d[i][j] > d[i][k] + d[k][j] thì cập nhật.

Gợi ý dạy: cho học sinh tự tính tay 1–2 bước cập nhật để hiểu “chèn k” là gì.
k=1, i=1, j=1

🌳 MST (Cây khung nhỏ nhất)

Prim / Kruskal

Nhận dạng đề

  • MST: cây khung có tổng trọng số nhỏ nhất.
  • Đề hay gặp: “xây đường / kéo dây / kết nối mạng / tiết kiệm chi phí”.
  • Prim: giống “Dijkstra trên cây MST”: luôn chọn cạnh rẻ nhất nối vào tập đã chọn.
  • Kruskal: sort cạnh tăng dần + DSU để tránh chu trình.
Bẫy: nếu đồ thị không liên thông, in “Graph not connected” hoặc xử lý theo đề (MSF).

🟨 Loang (Flood fill) — BFS trên lưới

đếm vùng 1

Loang là BFS/DFS trên ma trận: mỗi ô là một đỉnh, 4 hướng (hoặc 8 hướng) là cạnh. “Đếm đảo / đếm vết dầu” = đếm thành phần liên thông của các ô 1.

Tìm ô 1 đầu tiên rồi BFS lan ra.
Bẫy: nhầm 4 hướng/8 hướng; quên kiểm tra biên; quên reset visited.

🚀 Chủ đề nâng cao (thi tỉnh/thi quốc gia)

TopoSort • Euler tour • DSU rollback • Mo’s • HLD

1) Topological Sort (TopoSort)

  • Bài toán: sắp xếp thứ tự công việc với các ràng buộc trước–sau (DAG).
  • Kahn (BFS indegree): lấy dần các đỉnh indegree=0.
  • DFS topo: push vào stack khi “thoát” đỉnh.
  • Bẫy: nếu còn đỉnh chưa lấy mà queue rỗng ⇒ có chu trình (không có topo).
# Test topo có chu trình 4 4 1 2 2 3 3 1 3 4 # Expected: NO TOPO (cycle)

2) Euler Tour (tin/tout) + Subtree

  • Ý tưởng: DFS gán thời gian vào/ra: tin[u], tout[u].
  • Tính chất: subtree(u) là đoạn liên tiếp trong Euler: [tin[u], tout[u]].
  • Ứng dụng: query/update subtree bằng BIT/SegTree; đổi bài cây → bài mảng.
  • Bẫy: chọn root; input không phải cây; quên parent.

3) DSU Rollback (DSU có hoàn tác)

  • Ý tưởng: DSU union không path-compress; lưu “lịch sử” thay đổi vào stack để rollback.
  • Dùng khi: bài offline có thêm/xoá cạnh theo thời gian (dynamic connectivity) + chia đoạn thời gian.
  • Bẫy: nếu dùng path compression sẽ rollback rất khó; cần union-by-size/rank.
# Test ý tưởng (offline) add 1-2 add 2-3 ask 1 3 => YES remove 2-3 ask 1 3 => NO

4) Mo’s Algorithm

  • Ý tưởng: sắp xếp query theo block(L) rồi theo R để giảm số lần add/remove.
  • Dùng khi: nhiều query trên mảng tĩnh, cần trả lời offline (distinct, freq, XOR...).
  • Bẫy: block size ≈ sqrt(n); add/remove phải O(1).
# Test Mo (distinct count) a = 1 2 1 3 2 2 queries: [1,3]=2; [2,6]=3; [4,6]=2

5) HLD (Heavy-Light Decomposition)

  • Mục tiêu: query/update trên đường đi u–v (path query) bằng Segment Tree.
  • Ý tưởng: chia cây thành các “heavy paths”; đường u–v cắt thành O(log n) đoạn liên tiếp.
  • Kết hợp: HLD + segtree (sum/min/max).
  • Bẫy: build 2 DFS (size/heavy rồi decompose); chú ý head/pos.
