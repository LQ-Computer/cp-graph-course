HƯỚNG DẪN UP WEBSITE (MIỄN PHÍ)

1) GitHub Pages (khuyến nghị)
- Tạo repo Public trên GitHub.
- Upload toàn bộ file trong ZIP (giữ nguyên: index.html, lesson/, sim/).
- Settings → Pages → Deploy from a branch → main /(root).
- Link sẽ dạng: https://<username>.github.io/<repo>/

2) Google Sites (dạy học dễ)
- Tạo site → Insert → Embed → URL
- Dán link GitHub Pages (hoặc link bài cụ thể).
